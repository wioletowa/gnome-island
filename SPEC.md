# gnome-island@whyoolw — спецификация

Расширение для GNOME Shell 51 (Wayland), которое полностью заменяет и скрывает стандартный top bar
«островком» в стиле Dynamic Island с очень плавными анимациями.

## Технологии
- TypeScript + типы `@girs`, сборка в ESM (`extension.js`, `prefs.js`) через tsc/esbuild.
- Поддерживается только GNOME Shell 51.
- UUID: `gnome-island@whyoolw`, git-репозиторий, коммиты по этапам.

## Внешний вид
- Чёрная капсула (пилюля) по центру сверху, белый текст, лёгкая тень. Не зависит от темы.
- Стандартный `Main.panel` скрыт полностью, но его индикаторы переиспользуются.
- Полоса сверху резервируется (strut): развёрнутые окна начинаются ниже островка.
- Островок на всех мониторах.
- В fullscreen-окнах островок скрывается.
- В Overview островок остаётся видимым.

## Состояния

### Покой (свёрнут)
- Только время `HH:MM:SS`.
- Смена цифр — анимация прокрутки (одометр), каждая цифра отдельно.

### Играет музыка (MPRIS)
- Мини-обложка слева · время по центру · визуализатор справа.
- Визуализатор **настоящий**: GStreamer `pulsesrc`/`pipewiresrc` (monitor выходного устройства) → `spectrum`.
  Пайплайн работает только пока что-то играет; на паузе полоски плавно гаснут.

### Запись экрана / микрофон / камера / демонстрация экрана
- Островок расширяется: сбоку иконка соответствующего типа и таймер записи.
- Если одновременно идёт музыка и запись — островок **делится на два**: основная пилюля (музыка) +
  маленький круглый пузырь рядом (запись), который плавно «отпочковывается» и сливается обратно.

### Уведомление
- Содержимое островка заменяется на «иконка + название приложения» на время, заданное в настройках.
- Пока эта анимация активна, клик по островку открывает стандартное меню уведомлений/календаря GNOME.
- После окончания островок возвращается в прежнее состояние; уведомление остаётся в списке
  меню календаря как обычно.
- По умолчанию стандартные баннеры GNOME скрыты; в настройках можно отключить уведомления в островке
  и вернуть обычные баннеры.

### Раскрыт (по клику)
- Островок растягивается по горизонтали, но не на всю ширину экрана, чтобы вместились:
  воркспейсы, часы, раскладка клавиатуры, трей (AppIndicator / индикаторы других расширений,
  например Vitals), Quick Settings.
- Порядок по умолчанию: `воркспейсы | часы | язык · трей · QS`. Порядок настраивается в prefs
  (список с перетаскиванием, только в окне настроек).
- В раскрытом виде часы показывают ещё и дату.
- Клик по элементу открывает стандартное меню GNOME, привязанное к островку
  (часы → календарь + уведомления, QS → Quick Settings, язык → меню раскладки, трей → его меню).
- Сворачивание: клик вне островка, увод мыши + таймаут (если не открыто меню), `Esc`.

## Анимации
- По умолчанию пружинная физика (spring): прерываемые на лету без рывков, лёгкий перелёт.
- Морфинг размеров/радиуса скругления капсулы, кроссфейд содержимого с размытием.
- Всё настраивается: жёсткость, затухание, масса/скорость.

## Настройки (prefs, подробные)
- Размеры капсулы, отступ сверху, радиус скругления.
- Формат часов (по умолчанию `HH:MM:SS`), формат даты в раскрытом виде.
- Таймаут сворачивания при уводе мыши.
- Визуализатор: вкл/выкл, число полосок, чувствительность.
- Уведомления: островок вкл/выкл (выкл = обычные баннеры), длительность показа.
- Физика анимаций: жёсткость, затухание, масса.
- Порядок элементов раскрытого островка (drag & drop).
- Цвета (фон, текст, акцент).

## Совместимость
Установлены расширения, которые трогают панель: `just-perfection`, `panel-color-matcher`,
`Vitals`, `notification-icons`, `junk-notification-cleaner`. Индикаторы чужих расширений
переносятся в трей островка; расширения, которые красят/скрывают панель, могут конфликтовать —
это нужно проверить вживую.

## Этапы
1. Каркас TS-проекта, сборка, установка, скрытие панели + strut.
2. Свёрнутая капсула с часами-одометром, пружинный аниматор.
3. Раскрытие с переносом индикаторов панели и стандартными меню.
4. MPRIS + настоящий визуализатор.
5. Индикаторы записи/микрофона/камеры, разделение на два островка.
6. Уведомления в островке.
7. Мультимонитор, fullscreen, Overview.
8. Prefs (Adw), все настройки, drag & drop порядка.
