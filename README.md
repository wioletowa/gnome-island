# Island — Dynamic Island для GNOME

Расширение для GNOME Shell 51: полностью убирает верхнюю панель и заменяет её чёрной
капсулой по центру с пружинными анимациями.

- **В покое** — часы `HH:MM:SS`, цифры прокручиваются как счётчик.
- **Музыка (MPRIS)** — обложка, часы и настоящий спектр звука (GStreamer, монитор вывода).
- **Запись экрана / демонстрация / камера / микрофон** — иконка и таймер; если играет музыка,
  рядом отделяется маленький пузырь.
- **Уведомления** — островок на время показывает иконку и название приложения вместо баннера;
  клик открывает список уведомлений. Можно вернуть стандартные баннеры.
- **По клику** островок растягивается; часы всегда по центру, бока одинаковой ширины: воркспейсы, раскладка, трей
  и Quick Settings; их меню открываются под островком. Сворачивается кликом мимо, уводом
  мыши или Esc.
- Работает на всех мониторах, резервирует полосу под окна, прячется в полноэкранных окнах.
- Подробные настройки: размеры, цвета, форматы часов, физика пружин, порядок элементов
  (перетаскиванием).

## Сборка и установка

Расширение написано на чистом GNOME JavaScript (GJS, ES-модули), сборка не нужна.
Для установки нужны `make`, `unzip` и `glib-compile-schemas`:

```bash
make install
```

Затем перезайдите в сессию (Wayland) и включите расширение:

```bash
gnome-extensions enable gnome-island@whyoolw
```

Архив для extensions.gnome.org: `make pack` (появится в `dist/`).
